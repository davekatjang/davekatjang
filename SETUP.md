# Setup Notes

This repository is intended to be a GitHub profile repository.

## Required Repo Name

The GitHub repository must be named exactly the same as your GitHub username:

```text
davekatjang/davekatjang
```

GitHub renders the root `README.md` from that special repository on your profile page.

## Personalization

Before publishing publicly, replace:

- `project-one`
- `project-two`
- `project-three`

## Assets

- `assets/avatar.png`: upload in GitHub profile settings
- `assets/logo.png`: used in `README.md`
- `assets/banner.png`: used in `README.md`
- `assets/social-card.png`: use as repository social preview image
