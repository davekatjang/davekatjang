# GitHub Brand Guide

## Brand Position

**Name:** David Katjang  
**Handle:** `davekatjang`  
**Tagline:** Practical software, built with care.  
**One-liner:** I build clear, reliable software with an eye for product detail, automation, and maintainable systems.

## Voice

Direct, capable, and useful. Write like someone who ships real work and can explain tradeoffs without turning every note into a manifesto.

Use:

- Concrete verbs: build, simplify, automate, debug, ship
- Specific outcomes: faster workflows, clearer interfaces, reliable systems
- Short paragraphs and scannable lists

Avoid:

- Generic "passionate developer" phrasing
- Buzzword stacks
- Inflated claims without proof

- Headings: Inter, SF Pro, Arial, sans-serif
- Body: Inter, SF Pro, Arial, sans-serif
- Code labels: JetBrains Mono, SFMono-Regular, Consolas, monospace

### Logo Idea

The mark is a simple monogram: `DK` set inside a precise technical frame. It is intentionally plain enough to work as an avatar, repo badge, or README signature.

## GitHub Profile Structure

1. Banner
2. Short intro
3. Current focus
4. Selected projects
5. Working principles
6. Contact links

Keep it current. A concise profile with three real projects beats a long page of badges that never change.
